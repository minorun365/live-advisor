# 動作の詳細

## 動き方

| 段 | 何をするか | 使うもの |
|---|---|---|
| 見張り | 確定した発言を読み、持ち帰り、議論の詰まり、相手の質問を示す語を拾う | モデルなし |
| 判定 | 拾うべきことを選んでカードにする | Haiku |
| 調査 | 一般化した問いを公式情報で確かめる | Opus＋Web 検索 |
| 提案 | 議論の要点と調査結果から、進め方を1つ推奨する | Opus（道具なし） |
| 経緯 | 設定した記録フォルダから、同じ相手・同じ案件の過去の記録を探して要約する | Sonnet＋読み取りだけの道具（Read・Grep・Glob） |

調査の段は書き直した問いだけを受け取り、会議の発言を読みません。発言を読む判定と提案の段は Web 検索を使いません。経緯の段は会議の発言を読みますが、使えるのは記録フォルダを読む道具だけで、Web 検索もファイルの書き込みもできません。

## 経緯

設定の `contextFolders` に記録フォルダを書いたときだけ動きます。最初の判定が終わった直後に1回、同じ相手・同じ案件の記録が見つからなければ5分後にもう1回だけ探します。社名や話題が会議の冒頭で出るまでは当たらないためです。

見つかると「経緯」のカードを1枚出します。前回までの到達点、決まったことや残っている宿題、今日聞くとよいこと、根拠にした記録のファイルが並びます。ファイル名を押すと開きます。見つからなければカードは出ません。

経緯の要約は、そのあとの論点の提案と「今すぐ提案」にも渡します。1会議5回の上限には数えません。

## 判定の頻度

録音の開始から3分は動きません。その後は次のときに判定します。前回の判定から増えた文字が40字未満なら、どの場合も動きません。

- 前回から3分たったとき
- きっかけの語が出たとき（前回から1分以上あいている場合）
- パネルを開いたとき（前回から1分以上あいている場合）

## 今すぐ提案

質問は「？」で終わる18字以内、答えは25字以内、補足は25字以内の箇条書き3行までです。モデルの出力をアプリが数え、超えた行だけ Haiku で1回書き直します。書き直しが失敗したら元の文を出します。答えの出ていないカードは1行に縮めて表示します。

パネルの「今すぐ提案」を押すと、判定の頻度や録音開始からの3分を待たずに、その時点までの文字起こし（直近8000字まで）から今やるとよいことを1つ出します。Opus を道具なしで呼ぶので、Web 検索は使いません。1会議5回の上限には数えず、動いている間はもう一度押せません。

## カードの並び

カードは1列で、最後に変わったものが一番上に来ます。候補のときに出たカードも、答えが出た時点で一番上へ移ります。確信度0.6未満の候補は並べません。

未読のカードは薄い黄色です。パネルを1.5秒以上開いて閉じたとき、またはカードを押したときに既読になります。答えが後から出たカードはもう一度未読になります。

カードを押すと理由や出典が開きます。候補を押すと、開くと同時に調査か提案が始まります。閉じる操作はなく、古いカードは下へ流れていきます。

## 押さなくても動くカード

1会議5回までです。残りは候補として並び、押すと動きます。

| カード | 自動で動く条件 |
|---|---|
| 持ち帰り | 本人が持ち帰ると言い、調べて答えが出るもの |
| 相手の質問 | 相手の発言で、調べて答えが出て、確信度0.85以上 |
| 論点 | 確信度0.85以上。直近10分に同じ種類の提案があれば候補に回す |
| 食い違い | 自動では動かない |

話者が分からない文字起こしでは、「本人の持ち帰り」「相手の質問」の判定が働きにくくなります。文字起こしちゃんの日本語モードでヘッドホンを使うと話者が分かれます。

## 止め方

パネルの「この会議では止める」を押すと、その会議の判定を止めます。「再開する」で戻せます。次の録音では再び自動で動きます。

## スクリーンショット

パネルはふつうのウィンドウと同じようにスクリーンショットに撮れます。macOS では両方が同じ設定で決まるので、画面共有にも映ります。共有中に相手へ見せたくないときは、メニューバーのアイコンで閉じます。

パネルの外を押しても閉じません。範囲選択で撮るときのクリックで閉じないようにするためです。

## 保存されるファイル

会議フォルダ（`~/Library/Application Support/LiveTranslator/Sessions/<日時>/`）へ次のファイルを書きます。

| ファイル | 中身 |
|---|---|
| `advisor-cards.json` | カードの内容 |
| `advisor.md` | 読むための記録。AI の提案であり決定事項ではないと冒頭に書く |
| `advisor-queries.jsonl` | Web 検索へ送った問い |
| `advisor-context.jsonl` | 経緯の段が根拠にした記録のファイルのパス |

処理の時間、トークン数、費用は `~/Library/Logs/LiveAdvisor/live-advisor.log` に残ります。会議の本文は書きません。

## 設定

設定ファイルは任意です。ログイン時に起動したアプリには環境変数が渡らないので、ファイルで指定します。

```text
~/Library/Application Support/LiveAdvisor/config.json
```

```json
{
  "claudeCommand": "~/bin/my-claude"
}
```

`claudeCommand` は呼び出すコマンドです。既定は `claude` で、`~/.local/bin`、`~/.claude/local`、`~/.npm-global/bin`、`/opt/homebrew/bin`、`/usr/local/bin`、`/usr/bin`、`/bin` の順に探します。これ以外の場所に入れているときは絶対パスを書いてください。変更後はアプリを起動し直します。

`contextFolders` は経緯の段が読む記録フォルダの一覧です。案件ごとの議事録やメモを置いているフォルダを書きます。既定は空で、そのときは経緯の段は動きません。存在しないフォルダは無視します。

```json
{
  "contextFolders": ["~/notes/clients", "~/notes/meetings"]
}
```

記録フォルダの中身は、会議の発言と同じく Claude Code のログイン先へ送られます。送ってよいものだけを置いたフォルダを指定してください。

## 開発

```bash
scripts/test.sh
scripts/snapshot.sh /tmp/panel.png
scripts/e2e.sh /tmp/live-advisor-e2e
```

`e2e.sh` は架空の会議を流し、Claude Code を実際に呼んで最後まで通します。ログイン中の Claude の利用枠を少し使います。

## 文字起こしちゃんが無いとき

パネルを開くたびにアプリの ID で文字起こしちゃんを探します。見つからなければ、パネルの先頭に案内と導入ページへのボタンを出します。入れたあとは、次にパネルを開いたときに消えます。
